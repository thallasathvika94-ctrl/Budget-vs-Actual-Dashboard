Budget vs Actual Financial Analysis Dashboard

Project Overview

This project presents an interactive financial dashboard built in Microsoft Excel to analyze budgeted expenses against actual spending.

Objectives

- Compare budgeted and actual expenditure.
- Identify budget variances.
- Monitor spending across departments, categories, and months.
- Support data-driven financial decisions.

Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Excel slicers
- KPI cards
- Data visualization and conditional formatting

Dashboard Features

- Total Budget KPI
- Total Actual KPI
- Total Variance KPI
- Budget Utilization KPI
- Department, Category, and Month slicers
- Monthly Budget vs Actual comparison
- Department performance analysis
- Interactive filtering

Key Learnings

- Financial data analysis
- KPI design and calculation
- Interactive dashboard development
- Excel data visualization
- Financial performance monitoring

Files Included

- "Budget_Vs_Actual_Dashboard.xlsx" — Interactive Excel dashboard
- "Dashboard_Screenshot.png" — Dashboard preview

How to Use

1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Use the slicers to filter by department, category, or month.
4. Review the KPI cards and charts to explore financial performance.
